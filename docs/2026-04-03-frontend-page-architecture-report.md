# 2026-04-03 前端页面结构与独立页面报告

日期：2026-04-03

## 一、工作范围

本报告覆盖今天对前端页面结构的重构，重点是把单页式展示调整为更清晰的站点页面体系。

## 二、已完成事项

### 1. 站点入口拆分

- 将原先混合了“社团介绍”和“站内入口总览”的首页重新拆分。
- 当前页面结构为：
  - `/`：首页总览
  - `/portal`：社团介绍
  - `/stories`：文章札记
  - `/forum`：论坛聊天室
  - `/space`：个人空间
  - `/gallery`：展示墙

### 2. 社团介绍页与站内入口页拆分

- 将社团定位、活动、加入方式等内容放入单独的介绍页。
- 将原有“功能入口总览”保留为单独页面，避免介绍页和功能页混杂。

### 3. 内容页独立化

- 文章列表支持进入独立文章详情页：
  - `/stories/:articleID`
- 论坛列表支持进入独立帖子详情页：
  - `/forum/threads/:threadID`

### 4. 详情页能力

- 文章详情页展示完整正文、作者、标签和返回入口。
- 论坛主题详情页展示主题正文、回复列表和详情页内回复表单。
- 列表页卡片已改成跳转到对应详情页，而不是只在当前页内切换局部状态。

## 三、涉及文件

- `frontend/src/App.tsx`
- `frontend/src/api.ts`
- `frontend/src/content.ts`
- `frontend/src/App.css`

## 四、验证

- 前端构建通过：`npm run build`

## 五、结果

- 站点的信息架构已经从“单页聚合展示”演进到“多页面内容站”。
- 文章与帖子都已支持独立 URL 访问，便于后续继续补评论、面包屑、分享等能力。
