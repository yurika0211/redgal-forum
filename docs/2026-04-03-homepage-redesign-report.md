# 2026-04-03 首页改造报告

## 目标

根据 `docs/主页.md` 重做首页结构，使其更像正式社团主页，而不是“开发态门户页”。

## 已完成事项

### 1. Hero 区重做

- 首页 Hero 改为更大的社团门面区
- 强调社团历史、传承感与视觉小说主题
- 增加三句题记诗

### 2. 社团介绍重写

- 新增一段更完整的社团起源与沿革说明
- 把首页从“导航页”改成“内容与身份说明页”

### 3. 内容区重排

- 首页加入更明确的内容入口卡片：
  - 文章札记
  - 论坛讨论
  - 个人空间
  - 照片墙 / 展示墙

### 4. 照片墙下沉到首页底部

- 使用 `frontend/public/graphs/` 中的图片做首页底部精选
- 把照片墙从二级页面概念拉回首页下半区

### 5. 去掉首页中过于“开发态”的内容

- 移除首页中明显偏调试/联调用的面板感内容
- 让首页更接近真实社团站首页，而不是系统说明页
