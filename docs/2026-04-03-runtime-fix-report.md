# 2026-04-03 前端运行态修复报告

## 目标

修复今天开发过程中出现的“页面能启动但运行后异常/内容闪退/端口冲突”的问题。

## 已处理问题

### 1. 开发端口被占用

现象：

- `localhost:5173` 无法直接使用
- Vite 自动切到了其他端口

处理：

- 重新检查当前前端 dev server 状态
- 在端口空出来后重新拉起前端开发服务
- 恢复到 `http://localhost:5173/`

### 2. 分页接口切换后前端崩溃

现象：

- `Cannot read properties of null (reading 'items')`
- 页面内容一闪而过后消失

原因：

- 前端开始按分页结构读取 `items`
- 但运行中的后端可能仍返回旧数组格式

处理：

- 在前端加入兼容层
- 同时兼容：
  - 新分页结构
  - 旧数组结构
  - 空返回

### 3. `siteContent` 返回为空时页面区域被清空

现象：

- 某些页面或首页区块在接口返回空后直接消失

处理：

- 为 `portal`、`gallery` 等依赖站点内容接口的区域补本地兜底数据
- 接口拿不到数据时仍保留可显示内容

## 关键文件

- `frontend/src/App.tsx`
- `frontend/src/api.ts`

## 结果

- 前端页面不再因为旧/新接口结构差异直接崩溃
- 即使后端返回空内容，页面也不会整体白掉
- 开发服务端口问题已定位并恢复

## 验证结果

- `frontend`: `npm run build` 通过
